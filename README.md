# 全国防災マップ v3.4（X公式発信・地域検索）

## 追加機能
- 自治体詳細画面に、既存KMZ由来のXアカウント（`x`・`disasterX`）を表示
- 防災関連アカウントを優先。登録されたX URLのドメイン・ユーザー名を検証
- アカウント内の「災害・防災・避難・断水」検索リンク
- 地域名と災害キーワードからXの最新投稿を検索するリンク
- 公式Xの公開タイムラインを**ボタン押下後にのみ**読み込むオプション
- 投稿を閲覧するにはXのログインが必要な場合があり、埋め込みがブロックされる場合もある

## 重要
- **X投稿の自動収集・分類・災害発生判定は未実装**です。X API契約なしで外部投稿を勝手に取得・保持しません。
- Xアカウントは旧マイマップの登録情報を利用しており、現時点の公式性・有効性の検証はしていません。
- タイムラインは公開プロフィールに限り、表示に失敗する場合があります。その際はXへのリンクを利用してください。
- 気象庁のアラートは独立した情報源であり、Xの投稿では警報状態を変更しません。

## 反映方法
`public/index.html`, `public/app.js`, `public/style.css`, `public/x.js` を含め、ZIP内のファイルを既存GitHubリポジトリの同名階層に上書き。Cloudflareの自動デプロイを待ち、自治体詳細画面を確認してください。`wrangler.jsonc` の追加設定やシークレットは不要です。

## テスト
1. 自治体詳細にX登録リンクがあるか確認。
2. 公式X投稿検索と地域最新投稿検索が開くか確認。
3. 「公式Xの投稿をここに表示」をクリックして埋め込みが成功するか確認。失敗の場合は公式Xリンクを利用。
4. 登録アカウントのない自治体のフォールバック表示を確認。
5. 警報・自治体ポイント・検索が従来どおり動くか確認。

## 検証範囲
JavaScriptの構文チェック・ローカルデータ検査を実施。Cloudflare上での本番デプロイ、X側の表示確認は未実施。


## v3.5 修正: X埋め込みの無限読み込み対策
- `public/x.js` のみ変更。Xウィジェット読込は最大8秒、埋め込み生成は最大10秒でタイムアウト。
- 読み込み失敗時はエラー説明と「Xで投稿を見る」リンクを表示し、再試行可能。
- 投稿が実際に埋め込まれるかはX側のログイン・公開設定・ブラウザのトラッキング防止に依存します。APIによる自動取得ではありません。
- 更新時は `public/x.js` を上書きし、GitHubへCommitしてください。
