# ミエル防災 v5.17.1

災害時の水に焦点を当てた防災ポータル / Code for AICHI
設置先：https://code4aichi.org/mieru-bosai/

## 現在の機能
- 地図上の凡例・操作ボタン・取得状況を別々の行に整理。操作ボタンは3列で並びます。
- 豊田市・豊橋市・豊川市・一宮市・岡崎市・刈谷市・春日井市の水道関連公式ページへのリンクを地域詳細から確認可能。自動取得ではありません。
- 地域詳細に気象・水道・登録給水施設の状況と関連欄への入口を集約。施設の開設状況は未確認。
- 気象情報は取得から10分を超えた場合、地域詳細と地図で未確認として扱います。
- 地域詳細から共有URLをコピー可能。都道府県と地域名だけを共有し、現在地・保存情報は含めません。
- よく見る地域の欄から、保存済み地域・施設の件数を確認し防災メモを保存できます。
- 雨雲の実況を5分前へ切り替え、最新へ戻せます（画像の公開確認が必要）。
- 洪水浸水想定区域（想定最大規模）と内水浸水想定を切り替えて地図に重ねます。現在の冠水ではありません。
- 選択地域の登録位置を中心に、災害種別ごとの指定緊急避難場所・指定避難所を地理院地図で確認する入口を追加。開設状況は未確認。
- 初期地図は日本の主要地域・南西諸島・小笠原諸島が入る範囲。南鳥島・沖ノ鳥島などの遠隔の島は画面外です。震源（発表履歴）と雨雲（実況）を初期表示。
- 地図下の大雨・河川、断水・給水・備蓄、地震・津波は折りたたみ。使い方・公式リンク・出典は常時表示。
- 地図直下で雨雲の表示を切り替え。目的別入口から大雨・河川の詳細を展開。
- 河川別洪水予報の発表履歴を取得し、公式電文の自治体コードで選択地域に絞り込み。
- 自治体等の旧登録1,916地点と地域別の登録リンク。現在の公式性・有効性は全件未検証。
- 気象警報・注意報の区域照合、地震・津波の発表履歴。現在の災害・避難の必要性を判定する機能ではない。
- 横浜市・札幌市の緊急欄、名古屋市上下水道局の工事予定を先行連携。
- 名古屋市等620件・横浜市515件の登録給水施設を検索、現在地からの直線距離順、地図範囲検索。
- ブラウザ内への地域・施設の保存、保存管理、通信なしで読める地域・施設の防災メモの書き出し（公式リンクは通信が必要）。
- 水の備蓄量の概算チェック。

断水情報の全国網羅、避難指示・避難所の開設状況の自動連携、給水施設の現在の開設・給水状況の確認には未対応。
出典・利用条件・加工内容は public/data-sources.html に記載。

## 確認と反映
Node.jsとnpmを使用する。

```sh
npm install
npm test
npm run dev
```

Cloudflare Workers + Static Assets用。静的ファイルをGitHub Pagesに置くだけではAPIは実行されない。
既存のGitHub連携でデプロイする。Worker名は code4aichi-bousai、assets.run_worker_first は true。
カスタムドメインのルートは次の2つを使用する。
- code4aichi.org/mieru-bosai/*
- code4aichi.org/mieru-bosai

公式サイト全体の code4aichi.org/* へ割り当てない。本更新でDNS・ルートの変更は不要。
public/locations.json と public/water-events.geojson は更新ZIPに含めない。既存の登録地点と運用中の個別登録を残す。
