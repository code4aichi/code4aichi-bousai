# Code for AICHI 防災マップ v3.2（市区町村単位アラート）

## 変更内容
- 旧v3.1の1,916地点・Cloudflare Workers構成を引き継ぎ。
- `/api/areas` で気象庁の地域コード表を取得。
- 地点名＋都道府県名が気象庁class20区域名と一意に一致した場合だけ警報・注意報をマーカーに反映。
- 市区町村警報のある登録地点をリスト表示し、詳細画面でも確認可能。
- 絞り込みや注意報切り替え時も地図を再描画。
- 判定できない地点を安全と断定せず未判定として扱う。

## デプロイ
GitHubのリポジトリ直下に `public/`, `src/`, `wrangler.jsonc` 等を上書きしてコミットします。Cloudflare Workersのデプロイ結果を確認してください。

## テスト
1. `/api/alerts?office=230000` で `ok:true` を確認。
2. `/api/areas` で `ok:true` と `class20s` を確認。
3. アプリの全国マップの照合件数を確認。
4. 警報対象自治体だけにアラートが表示されるか気象庁公式サイトと照合。
5. 注意報を表示のON/OFFと自治体詳細を確認。

## 重要な制限
- 名古屋市の各区など元データの区名だけで、気象庁の区域が名古屋市一括の場合などは照合不可。自治体の行政区分と気象庁の警報区域は常に同じではありません。
- 海域・複数の市町村にまたがる登録地点は照合しないことがあります。
- 気象庁のデータ形式や地域名変更には継続的な保守が必要。
- 警報や注意報は災害発生の確定情報や避難指示を示すものではありません。
- 実データ環境での動作・公式発表との照合は未実施。公開前に必ず検証してください。
