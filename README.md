# Code for AICHI 全国防災マップ v3（気象警報・注意報）

## 追加した機能
- 気象庁の令和8年体系の警報・注意報JSONをCloudflare Workers経由で取得します。
- 全国47都道府県の**都道府県単位の概要**を表示し、警報・注意報が確認された地域の**代表地点**に `!` を表示します。
- 注意報表示ON/OFF、取得時刻、未取得地域の明示、5分ごとの再読み込み、手動更新。
- 自治体詳細に**都道府県内のどこか**で発表された警報・注意報を表示（当該自治体への発表と断定しません）。

## 重要な制約
- **災害が発生したことを検出する機能ではありません。気象庁の警報・注意報の発表状況です。**
- マーカーは都道府県代表地点で、**対象区域の境界や中心点ではありません**。個々の市区町村が警報対象であるとは限りません。
- 令和8年体系のJSONには、警報名が提供されないコードが存在する可能性があります。名前が不明なコードは危険度判定せず、**表示対象に含めません**。正式なコード表での統合・実データ検証が必要です。
- 検証環境から気象庁ライブJSONにアクセスできず、ライブ受信・正確な区分のエンドツーエンド検証は未実施です。**公開前に実データ照合必須**。
- 一部の官署・地域の取得に失敗した際は、その地域を**未確認**として表示します。取得失敗を警報なしとは扱いません。
- JMAデータを47地域分取得するため、初回応答時間やCloudflare利用条件の確認が必要です。サーバーキャッシュ180秒、クライアント更新5分。
- 避難情報、地震、津波、断水発生状況とは連動していません。

## デプロイ
現在のWorkers/GitHub連携のまま、リポジトリのルートに本ZIPの中身を上書きしてください。
重要なのは `src/worker.js` と `wrangler.jsonc` （WorkersのAPI）、`public/alerts.js` （UI）です。`public/locations.json` 等は引き続き含めています。
Build command は不要、deploy command は `npx wrangler deploy` を利用します。

## チェック
1. `/api/alerts?office=230000` を開いてJSONで `ok: true` が返るか確認。
2. `/api/alerts` を開いて `results` が47件あるか確認。
3. 全国マップを開き、取得時刻や確認不能地域が正しく表示されるか確認。
4. 気象庁公式画面と同時刻の警報・注意報件数、名称、対象地域を照合する。
5. 注意報の表示を切り替え、マーカーとチップが切り替わることを確認。

**本アプリは警報の唯一の情報源として使わないでください。** [気象庁公式](https://www.jma.go.jp/bosai/warning/) を必ず優先してください。


## v3.1 警報表示の修正（重要）
- 令和8年体系では `kinds[].name` は存在せず、`code` と `status` を読む必要があります。警報コード対応表を実装しました。
- 応答配列に含まれる複数の電文（VPWW55～61等）を全件走査するよう修正しました。
- 県代表座標に表示される警報マーカーは、その都道府県内の一部の区域に関するものも含みます。自治体単位の対象判定ではありません。
- `GET /api/alerts?office=230000` の `items` に実際の発表情報があるかをご確認ください。`ok:true` は接続成功のみを意味します。
- 初期デプロイ後、警報が一切表示されない場合は `GET /api/alerts` の `results` と画面の取得状況をご確認ください。実際の警報なしの場合もあります。
- 気象庁データ形式・警報コードは変更される場合があります。公開運用前に気象庁の現行資料と実際の発表情報を照合してください。
